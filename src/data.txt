📖 Overview

This repository documents Week 6 of my React.js learning journey as part of the DigiSkills program. This week focused on transitioning from basic React concepts to building more dynamic, scalable, and production-ready applications. The modules covered advanced state management, side effects, API integration, client-side routing, and reusable component patterns.
🎯 Learning Objectives

By completing this week's modules, I aimed to master the following core React concepts:

    State Management: Managing complex state with objects and lifting state up to share data between components.

    Event Handling & Forms: Handling user interactions, building controlled forms, and managing UI states (loading, error, success).

    Side Effects: Understanding the useEffect hook for lifecycle events, data fetching, and synchronization.

    API Integration: Connecting React applications to external APIs to fetch and display dynamic data.

    Routing: Implementing client-side navigation using React Router (v6+) with nested routes and dynamic parameters.

    Architecture & Reusability: Using the Context API for global state, creating custom hooks, and implementing reusable component patterns.
